# 灰犀牛推演系统（Grey Rhinoceros Forecast System）

面向未来的风险推演 Web 交互工具，将《新冠疫情系统需求分析与未来灰犀牛推演》报告转译为可交互的推演仪表盘。

## 功能 · 六大视图

| 视图 | 内容 |
| :--- | :--- |
| 总览 · 四段式框架 | 冲击源 → 传导链 → 政策对冲 → 结构残留；关键总量指标；三条推演规律；疫情时间轴；中国抗疫五阶段 |
| 行业冲击全景 | 供给侧 / 需求侧 / 资产负债表 / 逆势扩张 / 就业与中小企业 / 农业六大板块冲击与修复 |
| 历史对标 · 五面镜子 | 1918 大流感、2003 SARS、2008 金融危机、日本泡沫破裂、1957&1968 流感 |
| 灰犀牛监测 | 七类灰犀牛监测指标 + 预警阈值 + 三组共振配对联动告警 |
| 情景推演器 | 债务 × 地缘 3×3 矩阵 → 温和修复 / 滞胀拉锯 / 系统性共振三套情景 |
| 决策建议 | 五条建议 + 三处数据缺口 + 方法局限 + 覆盖口径 |

## 运行

纯前端零依赖，直接打开 `index.html` 即可（或任选静态服务器托管）。

## 技术

- 原生 HTML/CSS/JS（无框架、无 CDN、无构建）
- 数据驱动：所有指标与内容位于 `assets/data.js`，修改数据即可更新全站
- 浅色精密风（Linear Aesthetic）：玻璃拟态、微边框、辉光
- 数值与阈值均取自报告内标注来源的实测数据，不含编造数据
